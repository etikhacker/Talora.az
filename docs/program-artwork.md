# Program artwork

Generated for Talora using OpenAI's built-in image generation tool. Original 3:2 illustrations are optimized as 960px-wide WebP images (quality 82) with sharp. No reference-site images are distributed.

Used by the shared ProgramArtwork component on the landing page and internship catalogue. Images are decorative because each card already names its program.
